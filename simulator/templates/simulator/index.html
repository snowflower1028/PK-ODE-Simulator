                  the parameters to estimate, define your experimental groups and start the fit.

                Everything you set up can be saved with File → Save Session and restored later
                with File → Open Session.
              

            


            

              
Write one equation per line. Two kinds of lines are recognised:


              
Differential equations

              

                The left-hand side must be written as d<Name>dt. The name between
                d and dt becomes a compartment.
              

              
dA1dt = -ka*A1
dA2dt = ka*A1 - (CL/V)*A2


              
Derived variables

              

                Any other name = expression line defines a derived variable. Derived variables
                are substituted into the ODEs before solving, so they never become input parameters —
                use Model → Show Processed ODEs to see the result of that substitution.
              

              
C2  = A2/V
Kd  = koff/kon


              
Parameters

              

                Every remaining symbol — one that appears on a right-hand side but is never defined
                — becomes an input parameter you supply a value for. Above, that is
                ka, CL, V, koff and kon.
                Use Model → Edit Symbol Roles if you need to reclassify one.
              


              
Operators and functions

              
    
                
  • + - * / ** — ^ is also accepted and read as a power.
    • 
                
  • t is the time variable.
    • 
                
  • 
                  Built-in functions:
                  sqrt, exp, log/ln, abs,
                  sin, cos, tan,
                  asin, acos, atan,
                  sinh, cosh, tanh.
                
    • 
                
  • Blank lines and lines without = are ignored. Non-ASCII characters are stripped.
    • 
              


              
Full example — Michaelis–Menten elimination

              
dA1dt = -Vmax*C/(Km + C)
C     = A1/V

            


            

              

                Observed data is uploaded as CSV from Data → Observed Datasets. You can select
                several files at once; each becomes its own dataset.
              


              
Required shape

              
    
                
  • The first row is the header.
    • 
                
  • 
                  One column must be named Time (case-insensitive). It holds the sampling
                  times in the same unit as your simulation.
                
    • 
                
  • 
                  Every other column is a measured series. Name them however you like — after upload
                  you map each column to a model variable in the Observed Datasets panel.
                
    • 
              


              
Time,Plasma,Metabolite
0,0,0
0.5,72.4,1.1
1,88.1,3.6
2,77.3,7.9
4,51.2,11.4


              
How values are read

              
    
                
  • A row whose number of fields does not match the header is skipped.
    • 
                
  • A row with a non-numeric Time is skipped.
    • 
                
  • Any other non-numeric or empty cell is treated as a missing point, not as zero.

 About

PK ODE Simulator

              
Version 1.2

            

          


          

            An interactive web app for simulating pharmacokinetic profiles from a custom ODE system,
            and for estimating parameters against observed data. Write your model as differential
            equations, define dosing, run the simulation, and fit — all in the browser.
